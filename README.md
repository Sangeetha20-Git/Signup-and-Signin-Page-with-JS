# Tourist Authentication Project

## Overview

This project is a responsive Signup and SignIn system developed using HTML5, CSS3, Bootstrap 5, and JavaScript.

## Features

* User Registration (Signup)
* User Authentication (SignIn)
* Form Validation using JavaScript
* Show/Hide Password Feature
* Inline Error Messages
* Responsive Design for Mobile, Tablet, and Desktop
* Local Storage Authentication
* Tourist Landing Page after Successful Login

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## Project Structure

tourist-auth-project/

├── css/

└── js/
├── signup.js
└── signin.js

## How to Run

1. Download or clone the repository.
2. Open `signup.html` in a web browser.
3. Register a new account.
4. Sign in using the registered credentials.
5. You will be redirected to the Tourist Landing Page.
